Opsis: Local AI-Powered Document Intelligence

Opsis is a sophisticated local AI system that brings the power of Retrieval-Augmented Generation (RAG) and Large Language Models to your personal workflow. By seamlessly integrating CrewAI workflows with OpenDAV and Jira, Opsis transforms how you interact with documents and manage tasks.

Quick Start in 3 Steps

1. Install Opsis

# Clone the repository
git clone https://github.com/technickly/opsis.git
cd opsis

# Install dependencies
pip install -r requirements.txt

2. Configure Your Environment

# config.yml
opsis:
  data_dir: ./data
  index_dir: ./indexes

llm:
  provider: ollama
  model: llama3
  base_url: http://localhost:11434

rag:
  chunk_size: 1000
  retrieval_k: 5

3. Start Using Opsis

from opsis import Opsis

# Initialize
opsis = Opsis(config_path='config.yml')

# Index your documents
opsis.index_directory('/path/to/docs')

# Query your knowledge base
response = opsis.query("What are the key takeaways from Q4 reports?")
print(response.answer)
